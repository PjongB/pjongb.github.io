하드웨어 · 모터 제어

AX-12A의 위치를 읽고 목표 위치로 전달하는 제어 구조입니다. Half-Duplex와 Daisy Chain으로 다중 모터를 연결하고, 보드·배선·외장을 실물로 구성했습니다.

티칭 · 반복 실행

4축 자세를 Flash에 저장하고 재생합니다. 펌웨어는 10개 프리셋과 프리셋당 최대 30개 Step을 지원하며, 센서 감지 후 저장 동작을 실행합니다.

안전 제어

Home 완료 전 자동 동작을 제한합니다. E-STOP에서는 슬레이브의 실제 현재 위치를 읽어 고정하고, 이전 자동 동작 목표가 다시 실행되지 않도록 처리합니다.

01

착석과 측정 입력 분리

좌석 상태와 불기 시작 입력을 구분해 측정 중 이탈을 감지합니다. 복귀 대기와 시간 초과를 별도 상태로 처리합니다.

02

센서 변화량과 재측정

MQ-3와 DHT11의 기준값·측정값을 수집합니다. 측정 품질이 충분하지 않으면 RETRY로 전환하고 안정화 대기 후 다시 측정합니다.

03

UART 메시지로 역할 분리

MCU는 측정 시작·종료와 센서값을 전송합니다. Pi의 PASS / FAIL / RETRY / OTHER 응답에 따라 출력을 제어하며, 응답이 없을 때는 오류 상태로 복귀합니다.

시연 범위

발표 자료에는 정상 측정, 음주 감지, 대리 측정, 측정 중 이탈, 재측정 시나리오가 포함되어 있습니다. 시동 출력은 실제 차량 대신 LED로 확인한 프로토타입입니다.
