RFID 수신·서버 연동·기판 제작

책 정보를 읽는 회로를 제작하고, ESP32의 UART 수신과 Wi-Fi/HTTP 전송을 연결했습니다.

UART 수신과 HTTP 전송

장치 데이터가 서버까지 이어지는 통신 경로를 구성했습니다. STM32의 태그·위치 데이터를 UART로 받아 Wi-Fi/HTTP로 전달하고, RC522 회원카드 인식 후 대출·반납을 요청했습니다.

스캔부·대출부 기판 제작

스캔부와 대출부를 나누고 보드·RFID·모터 드라이버·리미트 스위치의 전원과 신호 배선을 구성했습니다. 회로를 실물 기판과 외관으로 제작해 장치 연동에 사용했습니다.

Android 앱과 사용자 조작

회원증 인식과 대출할 책 정보를 앱에서 확인하도록 구성했습니다. 센서에서 읽은 정보가 서버 처리와 사용자 확인으로 이어지도록 통신·하드웨어·앱의 접점을 맡았습니다.

RFID 인식 범위와 대량 수신 조정

한 번에 많은 태그가 읽히는 상황에서 인식 범위와 통신 속도를 조정하고, 구간별 응답을 확인했습니다.

인식 범위 · 스캔할 책에 맞춰 조정

조치 UHF RFID의 읽기 거리를 스캔 범위에 맞춰 조정했습니다. 센서 자료의 RF 출력 설정 명령을 확인하며 인식 범위를 다뤘습니다.

대량 수신 · 데이터량에 맞춘 통신 속도

문제 한 번에 많은 태그가 읽혀 통신 속도 조정이 필요했습니다. 조치 유입되는 데이터량에 맞춰 속도를 조정하고, ESP32 연동 구간의 수신 데이터를 확인했습니다.

검증 · UART 수신과 HTTP 응답
