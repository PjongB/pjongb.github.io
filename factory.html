주문부터 조립·적재까지 연결하는 스마트플랜트

버거 2대와 로봇팔 3대, 리니어 장치를 하나의 생산 순서로 연결합니다.

팀장 · PM · Jetson / STM32 · 공정·통신 시험2026.09 — 진행 중 · 09.29 업데이트
Jetson Orin NanoSTM32 · GPIOROS 2 · PythonOpenCV

1차 목표 · A제품 2개 통합 시연

부품 3개를 상차해 운반하고, A지그에서 조립한 뒤 완제품을 팔레트에 적재합니다. Host는 운송 잔여와 완제품 잔여를 따로 관리하고, 두 버거의 복귀까지 확인하도록 설계했습니다.

장치별 실행 책임

Host PC는 주문·작업 순서·결과를 관리합니다. 각 버거 Pi는 Nav2·ArUco·IR 정지를 실행하고, 팔1은 자재창고 Jetson, 팔2는 Pi, 팔3와 리니어는 하나의 Pi에서 제어하는 구조입니다.

현재 확인한 범위와 다음 목표

웹 시뮬레이션·Host HTTP 시험과 통신 규격 초안을 작성했습니다. 10월 7일 실물 통합 시연을 준비 중이며, 와플 지게차와 제품 B·창고 층별 적재는 최종 확장 범위입니다.

센서 입력부터 공정 시험까지

기획과 팀 운영을 맡고, Jetson 카메라 환경·STM32 센서 판별·Host 시험을 구현했습니다.

Jetson · 자재창고 카메라 환경

Jetson Orin Nano에 ROS 2 Python 패키지를 구성하고 USB 웹캠 입력과 웹 JPEG 스트림을 확인했습니다. OpenCV 로컬 영상 모드도 추가했습니다. 재고·집기 위치 인식과 모방학습 추론은 후속 과제입니다.

STM32 · 적외선 흑백 판별

Flying Fish 센서를 실제 장착 높이에 고정하고 가변저항으로 흰색·검은색 판별 임계값을 조정했습니다. 센서의 디지털 출력을 GPIO로 읽어 구분되는 것을 확인하고, 데모 터틀봇 하드웨어 구성에도 참여했습니다.

팀장 · PM / 공정·통신 시험

1차 시연과 최종 확장 범위를 나누고, 장치별 역할·완료 조건·Jira 작업을 정리했습니다. 웹에서 주문 1–20개와 단계별 진행을 구현하고, Host 지시 → 완료 회신 → 다음 지시의 HTTP/JSON 시험 기능을 추가했습니다.

완료 조건이 확인될 때 다음 공정으로

영상 확인 방식과 작업 지시 단위를 개선하고, 공정 전환 조건을 화면에 드러냈습니다.

HOST 시험 · 지시 단위 개선

39경유점 중심 단계→11목적지·작업 단위

A제품 2개 주문의 웹 시험 기준

  1. 작업 지시이동 · 상차 · 조립 · 적재
  2. 실행과 완료 조건 확인도착 · 지그 위치 · 부품 수량
  3. 완료 회신 확인조건 미충족·연결 단절 시 다음 단계 차단
  4. 다음 공정과 잔여 수량 갱신운송 시작과 팔레트 적재를 구분

웹 HTTP 시험에서 확인한 흐름입니다.
실물 ROS 연동은 별도 구현·검증 대상입니다.

영상 지연 · 로컬 확인 경로 추가

원격 실행 시 영상 창의 DISPLAY 문제와 웹 영상 지연을 확인했습니다. JPEG 품질·전송 프레임·버퍼 설정을 조정하고 --local 모드를 추가했습니다. 로컬 영상이 빠르게 동작함을 확인했으며 지연 시간은 아직 실측하지 않았습니다.

과도한 단계 분할 · 목적지 단위로 변경

중간 주행 노드마다 Host 승인을 기다리던 흐름을 목적지·작업 단위로 묶어, 2개 주문의 웹 시험을 39단계에서 11단계로 정리했습니다. 실물 통신 초안도 명령 수락과 최종 완료 결과를 구분하도록 설계했습니다.

다음 단계 오진행 · 조건과 회신 확인

도착·부품 적재·조립·리니어 위치·팔레트 적재 조건을 빨강/초록으로 표시했습니다. 완료 회신과 연결 상태를 확인해 다음 단계를 허용하고, 단계 실행·중복 클릭·회신·단절 관련 자동 검사를 추가했습니다.
