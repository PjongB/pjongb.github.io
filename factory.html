팀장·PM으로 공정의 역할과 완료 조건을 정리하고, Jetson 영상·STM32 센서·Host 시험을 구현했습니다.

전체 시스템

Host가 주문과 작업 순서를 관리하고, 이동 로봇 2대·로봇팔 3대·리니어 장치가 운반·조립·적재를 수행하는 구조입니다.

공정 시뮬레이션 ↗

내가 맡은 일 · 팀장 / PM · 공정 시험

1차 시연과 확장 범위를 나누고 장치별 역할·완료 조건·Jira 작업을 정리했습니다. 주문 1–20개와 지시 → 완료 회신 → 다음 지시의 HTTP/JSON 시험을 구현했습니다.

Jetson · 자재창고 카메라 환경

Orin Nano에 ROS 2 Python 환경과 USB 웹캠 입력을 구성했습니다. 웹 JPEG 스트림과 OpenCV 로컬 영상 모드를 추가해 현장에서 영상을 확인할 경로를 만들었습니다.

STM32 · 실제 장착 조건에서 센서 조정

Flying Fish 적외선 센서를 실제 높이에 고정하고 가변저항으로 흑백 판별 임계값을 조정했습니다. 디지털 출력을 GPIO로 읽어 구분되는 것을 확인하고 데모 터틀봇 하드웨어 구성에도 참여했습니다.

영상 확인 방식과 작업 지시 단위를 개선하고, 공정 전환 조건을 화면에 드러냈습니다.

HOST 시험 · 지시 단위 개선

39경유점 중심 단계→11목적지·작업 단위

A제품 2개 주문의 웹 시험 기준

  1. 작업 지시
  2. 실행과 완료 조건 확인
  3. 완료 회신 확인
  4. 다음 공정과 잔여 수량 갱신

웹 HTTP 시험 기준 · 실물 ROS 연동은 별도 검증

영상 지연 · 로컬 확인 경로 추가

원격 실행 시 영상 창의 DISPLAY 문제와 웹 영상 지연을 확인했습니다. JPEG 품질·전송 프레임·버퍼 설정을 조정하고 --local 모드를 추가했습니다. 로컬 영상이 빠르게 동작함을 확인했으며 지연 시간은 아직 실측하지 않았습니다.

과도한 단계 분할 · 목적지 단위로 변경

중간 주행 노드마다 Host 승인을 기다리던 흐름을 목적지·작업 단위로 묶어, 2개 주문의 웹 시험을 39단계에서 11단계로 정리했습니다. 실물 통신 초안도 명령 수락과 최종 완료 결과를 구분하도록 설계했습니다.

다음 단계 오진행 · 조건과 회신 확인

도착·부품 적재·조립·리니어 위치·팔레트 적재 조건을 빨강/초록으로 표시했습니다. 완료 회신과 연결 상태를 확인해 다음 단계를 허용하고, 단계 실행·중복 클릭·회신·단절 관련 자동 검사를 추가했습니다.
